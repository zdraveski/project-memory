How it works

You keep working as you do now. Claude Code keeps a notebook of notes for each project; project-memory looks after it and does four things for you.

  1. After every reply

    The exchange goes into a journal on your computer, with a note of where you stopped.

  2. The next conversation

    Claude starts with a short briefing, usually under 1,000 tokens, so it knows where things stand.

  3. When it gets long

    Before Claude Code shortens a conversation, Claude saves its notes. Afterwards it's told what you asked and what it last said.

  4. When something goes wrong

    A version of your notes is saved after each reply that changes them, so a lost note can come back.

What you get

It helps most when you come back to the same project over days or weeks. For a quick one-off question, you won't notice much difference.

A journal you can ask

Every exchange is kept, one file per day. Ask about earlier work in your own words, and Claude searches the journal and your notes, and tells you when it happened. The journal isn't loaded into the conversation; it's only searched when you ask.

> What did I work on last week?
Mon the pricing table, three plans Tue checkout copy, first draft Thu logo colours, kept amber

Every change kept

A note deleted or overwritten by mistake comes back when you ask. Needs Git.

Long tasks stay on track

When a long conversation is cut down to a summary, the task in progress isn't lost.

Lessons shared

Teach Claude a habit once, and every project knows it.

Two windows, no clashes

Two Claude windows on one project don't overwrite each other.

Forget on request

Claude lists the journal entries that match, and removes the ones you confirm.

Your work stays on your computer

project-memory makes no internet connections. What it saves stays in Claude Code's own folder in your home folder, and it never writes in your projects.

  • Secrets are blanked out

    Keys, tokens and passwords become [redacted] before anything is saved.

  • Keep a part out

    Put text between <private> and </private>, and it isn't saved.

  • Keep a conversation out

    Type <private-session> in any message. What was saved of it before is removed, except the history's copy of days that are already over.

  • Forget on request

    Claude removes the journal entries you confirm. For days already over, a copy stays in the history until you delete it.

No tool catches every secret, so use the tags for anything sensitive. And what Claude reads during a conversation goes to Anthropic with the rest of it, as with Claude Code's own memory.

Built with care

It runs after every reply, on your notes, so it has to be right. These checks run on every change, and the biggest before every release.

  • Tested on every system

    Windows, macOS and Linux on Node.js 24 and 26, and Linux on 22 too, on every change.

  • Its tests are tested

    Before a release, more than 3,000 small bugs are planted in the code on purpose, and the tests must catch every one.

  • Thrown at the hard cases

    Before a release, ten minutes of random conversations, time-zone changes, disk errors and interrupted runs, on 17 machines at once.

  • Nothing extra installed

    No dependencies to download, and the code is open for anyone to read. MIT licence.

Install it

It takes about a minute. Not sure what you have? Ask Claude: "Do I have Node.js 22 or newer, and Git?"

  1. In Claude Code, type these two lines. When the second opens a menu, choose to install it for you (user scope), so it works in every project.

    /plugin marketplace add zdraveski/project-memory
/plugin install project-memory@project-memory

  2. Close Claude Code and open it again.

  3. Check it's working. Every line should start with ok.

    /project-memory:memory doctor

    Until Claude finishes its first reply, one line says it's waiting for that reply. That's normal.

What you need

  • Claude Code with its built-in memory on. It is, unless you turned it off.
  • Node.js 22 or newer. Choose the LTS version.
  • Git, optional. Without it, everything works except bringing back old versions of notes.
  • Windows, macOS or Linux.

Questions people ask

Does it send anything over the internet?

No. It makes no internet connections, and what it saves stays in Claude Code's own folder in your home folder. What Claude reads during a conversation goes to Anthropic with the rest of it, as with Claude Code's own memory.

Does it slow Claude down or fill the conversation?

Each conversation starts with a short briefing, usually under 1,000 tokens. The journal isn't loaded; Claude searches it only when you ask about earlier work.

How much disk space does it use?

A journal entry is usually under 3 KB. A very busy project adds up to about 40 MB a year.

Can I use it on two computers?

Each computer keeps its own notes and journal; they don't sync. Don't sync the memory folder yourself (Dropbox, OneDrive): each computer would undo the other's "forget".

My model holds 200,000 tokens. Do I need to change anything?

Yes, for long conversations. It assumes a window of 1,000,000 tokens, so the reminder to save notes never comes. Ask Claude: "Is my context window 200,000 tokens?" If it is, ask: "Add CLAUDE_CODE_AUTO_COMPACT_WINDOW set to 200k under env in my Claude Code settings," then restart Claude Code.

How do I pause or remove it?

To pause it, run claude plugin disable project-memory@project-memory in a terminal and restart Claude Code. To remove it, type /plugin uninstall project-memory@project-memory in Claude Code. Your notes and the journal stay either way; the privacy policy says what to delete by hand.
