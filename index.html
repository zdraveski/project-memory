What you get

What it does for you.

It looks after the notebook Claude Code keeps for each project, and adds a journal of everything you did. It helps most when you come back to the same project over days or weeks.

Picks up where you left off

A new conversation starts already knowing where the last one stopped.

A journal you can ask

Every exchange is kept. Ask about earlier work in your own words, and Claude tells you when it happened.

Keeps old versions of notes (needs Git)

A note deleted or overwritten by mistake comes back when you ask.

Keeps long tasks on track

Before a long conversation is shortened to a summary, Claude saves its notes, and afterwards it's told where it was.

Shares lessons across projects

Two windows, no clashes

Two Claude windows on one project don't overwrite each other.

Your privacy

Stays on your computer.

It makes no internet connections. What it saves stays in Claude Code's own folder, in your home folder.

  • Never goes online

    No account, no API key, no servers.

  • Secrets are blanked out

    Common kinds of keys and passwords become [redacted] before anything is saved.

  • Keep text out

    Put it in <private> and </private>.

  • Keep a conversation out

    Type <private-session>. What was saved before is removed, except the history's copy of days already over.

Anthropic still sees your conversation, as with Claude Code's own memory. No tool catches every secret, so use the tags for anything sensitive. Ask Claude to forget something, and it removes the journal entries you confirm.

These checks run on every change, and the biggest before every release.

Install

Ready in a minute.

Not sure what you have? Ask Claude: "Do I have Node.js 22 or newer, and Git?"

  1. In Claude Code, type these two lines. When the second opens a menu, choose to install it for you (user scope), so it works in every project.

    /plugin marketplace add zdraveski/project-memory
/plugin install project-memory@project-memory

  2. Close Claude Code and open it again.

  3. Check it's working. Every line should start with ok.

    /project-memory:memory doctor

    Until Claude finishes its first reply, one line says it's waiting for that reply. That's normal.

What you need

  • Claude Code with its built-in memory on. It is, unless you turned it off.
  • Node.js 22 or newer. Choose the LTS version.
  • Git, optional. Without it, everything works except bringing back old versions of notes.
  • Windows, macOS or Linux.

Questions

Questions people ask.

Does it send anything over the internet?

No. It makes no internet connections, and what it saves stays in Claude Code's own folder in your home folder. What Claude reads during a conversation goes to Anthropic with the rest of it, as with Claude Code's own memory.

Does it slow Claude down or fill the conversation?

Each conversation starts with a short briefing, usually under 1,000 tokens. The journal isn't loaded; Claude searches it only when you ask about earlier work.

How much disk space does it use?

A journal entry is usually under 3 KB. A very busy project adds up to about 40 MB a year.

Can I use it on two computers?

Each computer keeps its own notes and journal; they don't sync. Don't sync the memory folder yourself (Dropbox, OneDrive): each computer would undo the other's "forget".

My model holds 200,000 tokens. Do I need to change anything?

Yes, for long conversations. It assumes a window of 1,000,000 tokens, so the reminder to save notes never comes. Ask Claude: "Is my context window 200,000 tokens?" If it is, ask: "Add CLAUDE_CODE_AUTO_COMPACT_WINDOW set to 200k under env in my Claude Code settings," then restart Claude Code.

How do I pause or remove it?

To pause it, run claude plugin disable project-memory@project-memory in a terminal and restart Claude Code. To remove it, type /plugin uninstall project-memory@project-memory in Claude Code. Your notes and the journal stay either way; the privacy policy says what to delete by hand.
