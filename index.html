Claude remembers where you left off.

project-memory is a free plugin for Claude Code. After every reply it keeps a journal of your work and a note of where you stopped, so the next conversation starts where the last one ended.

  • Free and open source
  • No account or API key
  • Never goes online

What changes

Claude Code keeps a notebook of notes for each project. project-memory looks after that notebook and adds a journal of everything you did. It helps most when you come back to the same project over days or weeks.

Ask in your own words

There's nothing to learn. Most of these have a command too, if you'd rather type one.

"What did we decide about the logo in September?"
Claude searches your notes and the journal, and answers with the date.
"Where did we leave off?"
Claude reads the record of your last conversation.
"I deleted the note about pricing by mistake. Bring it back."
Claude restores it from the history of your notes.
"Forget the password I pasted yesterday."
Claude lists the journal entries that match, and removes the ones you confirm.
"Remember that I prefer short answers."
Claude saves a note.
"Remember for all my projects that I like plain language."
Claude saves it to the notebook every project shares.

Your work stays on your computer

project-memory makes no internet connections. What it saves stays in Claude Code's own folder in your home folder, and it never writes in your projects.

  • Secrets are blanked out

    Keys, tokens and passwords become [redacted] before anything is saved.

  • Keep a part out

    Put text between <private> and </private>, and it isn't saved.

  • Keep a conversation out

    Type <private-session> in any message. What was saved of that conversation before is removed, except the history's copy of days that are already over.

  • Forget on request

    Ask Claude to forget something, and it removes the journal entries you confirm. For days that are already over, a copy stays in the history until you delete it.

No tool catches every secret, so use the tags for anything sensitive. And what Claude reads during a conversation goes to Anthropic with the rest of it, as with Claude Code's own memory.

Read the privacy policy: everything it reads and saves, and how to delete it.

Install it

It takes about a minute. Not sure what you have? Ask Claude: "Do I have Node.js 22 or newer, and Git?"

  1. In Claude Code, type these two lines. When the second opens a menu, choose to install it for you (user scope), so it works in every project.

    /plugin marketplace add zdraveski/project-memory
/plugin install project-memory@project-memory

  2. Close Claude Code and open it again.

  3. Check it's working. Every line should start with ok.

    /project-memory:memory doctor

    Until Claude finishes its first reply, one line says it's waiting for that reply. That's normal.

You need Claude Code with its built-in memory on (it is, unless you turned it off) and Node.js 22 or newer. Git is optional: without it, everything works except bringing back old versions of notes. It runs on Windows, macOS and Linux.
