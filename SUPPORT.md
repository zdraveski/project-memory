# Getting help

- **A question**, such as how to do something or whether it should work
  this way: ask in
  [Discussions](https://github.com/zdraveski/project-memory/discussions).
  Short answers to common ones are in [Questions people ask](docs/faq.md).
- **Something doesn't work.** Type `/project-memory:memory doctor` in Claude
  Code first: a line that starts with `PROBLEM` says what to do. If that
  doesn't fix it,
  [open an issue](https://github.com/zdraveski/project-memory/issues/new/choose)
  and paste what the check printed. Issues are public, so leave out keys,
  passwords and private text.
- **A security or privacy problem**, such as a secret saved or a private
  conversation recorded: report it privately, as [SECURITY.md](SECURITY.md)
  says, not in an issue.
