# 1.6.0 Step 2: Search Filters and the Shared Reader (release 1.5.4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `memory search` can be narrowed to a file, to the user's own words and to one conversation, and the code that later hooks will share has a home.

**Architecture:** A new module `recall.mjs` takes the word splitter out of `memory.mjs` unchanged and adds three small tests on a journal entry (changed this file, is a helper's report, belongs to this conversation). `search()` stays in `memory.mjs` and takes the three filters as options. The CLI gains `--file`, `--asked` and `--conversation` for `search`.

**Tech Stack:** Node.js 22+ ES modules, `node:path`, `node:assert`. No dependency.

**Spec:** `docs/specs/2026-11-19-1.6.0-design.md`, sections "1a. Search filters", "New files" (the `recall.mjs` row), "Build order" (the paragraph "Order changed on 2026-11-20" and step 2), "Testing". Part of release 1.5.4. ## Decisions this plan makes (beyond the spec)

- **`search()` does not move.** The spec's "find entries by words" in `recall.mjs` is the splitter and the matchers that depend on it. The ranking stays in `memory.mjs`: no hook needs it.
- **What moves, as one block with no edit inside it:** `memory.mjs:224-295`, that is `STOP`, `VERSION`, `isVer`, `verRe`, `cutEn`, `stem`, `words`, `CJK`, `NC`, `alone`, `plain`, `starts`, `forms`, `count`, `has`. `recall.mjs` exports each name `memory.mjs` uses, and `memory.mjs` imports them. `enforce.mjs:44` has its own `words` and is not touched.
- **`recall.mjs` imports `fold` from `journal.mjs`** (`journal.mjs:54` gains `export`). It imports nothing from `memory.mjs`.
- **With any of the three filters, notes are left out.** A note has no changed files, no request and no conversation. The footer says so (Task 2).
- **`--file` compares text only.** Both sides: `\` becomes `/`, a leading `./` and trailing `/` go, and case is folded as the journal folds it (`fold`: Windows and macOS). A match is an equal path, or the given path being the end of a changed path right after a `/`. An absolute path given for a file the journal saved as a relative path finds nothing, and the miss message says what to try.
- **`--conversation` matches the session id.** The id is the part of the entry's `t` after its last `/`. The entry matches when that id starts with the given text, case ignored. When an entry has no `t`, its 8-character tag `s` is used: it matches when the given text starts with `s` or `s` starts with the given text.
- **`--asked` leaves out every helper entry and every entry whose `Asked` or `Answered` is exactly `[private]`**, with or without words. A turn marked private keeps its request in `Asked` and has `[private]` only in `Answered` (`journal.mjs:85-87`), so both are checked. With words, only `Asked` is scored (3 a term, the rarity and length weights as today).
- **A search with filters and no words is a list**, in the form of today's search by date: newest first, 30 by default. In that list helper entries are left out as today, except with `--file` or `--conversation`, where the user asked for a file's or a conversation's entries and a helper's report is one of them.
- **Left for later steps:** the stricter file test of the change hook (step 4), the rare-word test (step 5), the session file.

## Review Focus

1. A path with the other slash or another case: `--file SRC\Cart.js` on Windows for an entry that holds `src/cart.js`. Expected: found on Windows and macOS, and on Linux only when the case is equal. Test: Task 1, `one file, two spellings`.
2. A short name that is the tail of another name: `--file art.js` must not find `src/cart.js`. Test: Task 1, `the end of a path counts only at a folder`.
3. `--asked private` must not list every private turn. Test: Task 2, `a private turn is never an --asked hit`.
4. A filter that takes a value, given last with no value, or given twice. Expected: the existing "needs a value" refusal, and the first value wins as `opt()` reads it. Test: Task 3, `a filter without its value`.
5. A project whose journal holds only helper entries, searched with `--asked`. Expected: the miss message, exit as a miss today, no crash. Test: Task 2, `only helpers`.
