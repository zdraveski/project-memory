# 1.6.0 step 15: privacy and transcript modules (plan)

Spec: `docs/specs/2026-11-24-privacy-and-transcript-modules.md`, part 2.
Decision: `docs/adr/0001-privacy-decided-in-one-module.md`.

**When.** After 1.5.8 has shipped, because this step starts from its `norm`
in `store.mjs`. It comes first in the 1.6.0 order after 1.5.4:
15, 3, 4, 5, 6, 7, 8, 9, 11, 12, 14.

**What it is.** A pure move in three pull requests. After each one, every
existing check passes unchanged; only an import line in a test may change.

**How to work.**
- Branch from `master`.
- Run `node tools/check.mjs` after each edit.
- Sign off every commit.
- Keep local mutate batches to about 8 to 12 lines.

## PR A: `src/privacy.mjs`

1. **Write the direct tests first:** `test/privacy.test.mjs`, in-process,
   using the names that will exist.
   - A table over the six sources, each with its file absent, present and
     unreadable (make it a directory).
   - An unreadable file must answer "private" from every exported question.
   - Fullwidth and zero-width tags.
   - The compaction note's looser `<private` check.
   - Pruning: `.private-sessions` keeps the newest 999; `.memory-off` keeps
     what is on disk plus the newest 100, up to 10,000.
2. **Create `src/privacy.mjs`** and move in, as they are:
   - From `handoff-log.mjs`: `PRIVATE`, `PRIVATE_SESSION`, `hushed`, `off`,
     `offLine`, `unreadable`, `FORGOTTEN`, `forgotten`, `unsay` and its `put`.
   - From `store.mjs`: `QUIET`, `OFF`, `PROJECT_OFF`, `isOff`, `OFF_PERIODS`
     and `wasOff`.
   - Imports: Node built-ins and `store.mjs` only.
3. **Apply the one rule.**
   - The module's answers treat "unreadable" as private.
   - Keep a way for the Stop hook to learn that a file was unreadable
     (`handoff-log.mjs:827` and `:842` throw so the failure is recorded), and
     keep that behaviour.
   - The retry count is the caller's choice. The default is 3; the git-rule
     hook uses 1.
4. **Write down the deliberate difference.** Move the compaction note's looser
   check into `privacy.mjs` under its own name, with the comment from
   `compact-gate.mjs:142`.
5. **Switch every caller to `privacy.mjs`:**
   - `compact-gate`, `journal`, `memory`, `memory-tier`, `enforce` (drop its
     copy of the pattern and its `tagged()` reader), and `handoff-log`.
   - The tests and `tools/fuzz.mjs`.
   - No re-exports from `handoff-log` or `store` of anything that moved.
6. **Delete the dead code:** the `try/catch` around `isOff` at
   `compact-gate.mjs:395`.
7. **Update the mutant tree.** Add `test/privacy.test.mjs` to
   `tools/suites.mjs` and the mutant tree, as the other suites are. Repoint any
   hand mutants whose file changed (see "What bit before" in CONTRIBUTING).
8. **Check the speed.** Run `node tools/bench.mjs` before and after, and put
   both `'PreToolUse git'` numbers in the PR. The limit is 7.

## PR B: `src/transcript.mjs`

1. **Read first.** Read `turns()` (`handoff-log.mjs:281-407`) in full. List any
   privacy branch beyond `:363` in the PR.
2. **Write the direct tests first:** `test/transcript.test.mjs`, in-process.
   - Fixture records, read forward and backward.
   - A line cut at each byte reader's chunk edge.
   - Helper records skipped unless asked for.
   - `turns()` output on the fixtures equals today's output. Capture it from
     master before the move and commit it as the expected value.
3. **Create `src/transcript.mjs`** with two levels, records and turns, and
   move in:
   - From `handoff-log.mjs`: `readTail`, `text`, `asked`, `prompt`, `own`,
     `unwrap`, `queuedText`, `toolAnswers`, `refused`, `editedFile`, `turns`,
     `promptBefore`, `goesOn`, `lastTurn`, `transcripts`, and the record-type
     filters at `:41-42`.

4. **Fold the byte readers** into the records level, keeping each one's
   limits:
   - `store.mjs:139` (64 KB chunks up to 4 MB, with a 12,300-byte overlap).
   - `handoff-log.mjs:536` (1 MB backwards, up to 256 MB).
   - `journal.mjs:213`, `:371` and `:525`, and `past` at `:641-701`.
   - `compact-gate.mjs:120`'s parse loop.
5. **Switch the callers** (`handoff-log`, `journal`, `compact-gate`, `memory`,
   `store`, the tests, `tools/fuzz.mjs`) to import directly.
6. **Check the import loop.**
   - Check that `journal` and `compact-gate` no longer import `handoff-log` for
     anything that moved.
   - List in the PR any name they still take from it.
7. **Update the mutant tree.** Add `test/transcript.test.mjs` to the suites
