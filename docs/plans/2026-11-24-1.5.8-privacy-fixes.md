# 1.5.8 privacy fixes: plan

Spec: `docs/specs/2026-11-24-privacy-and-transcript-modules.md`, part 1.

**What it is.** A patch release made of bug fixes only, shipped with PR #230.
Each fix has a failing test first, so the history shows the red commit before
the fix.

**How to work.**
- Branch from `master`.
- Run `node tools/check.mjs` after each edit.
- Sign off every commit.
- Process: `feedback-proportionate-process`. Tests run once in CI, there is one
  fresh review per release, and "release 1.5.8" means merge on green.

## Task 1: the git-rule hook normalizes and skips helper records

Files: `src/store.mjs`, `src/handoff-log.mjs`, `src/enforce.mjs` and
`test/enforce.test.mjs`. The test file is in-process.

1. **Write the failing test.** In `test/enforce.test.mjs`, write a transcript
   whose typed user text holds `＜private-session＞` (U+FF1C, U+FF1E), and a
   second one with `<private​-session>`. `privateTurn` must return `true`
   for both. Write a third transcript where the tag appears only in a record
   with `isSidechain: true`; `privateTurn` must return `false` for it, the
   way `turns()` ignores helpers. Run the tests and see them fail.
2. **Move `norm`.** Move it from `handoff-log.mjs:188` to `store.mjs` and
   export it there. `handoff-log.mjs` imports it from `store.mjs` and re-exports
   it, so `compact-gate` and `journal` don't change.
3. **Fix `privateTurn`** in `enforce.mjs:195-208`:
   - Pre-filter on `RE.test(norm(l))`, not on the raw line.
   - Parse the line and `continue` when `r.isSidechain`.
   - Test the typed text as `norm(b.text)`.
4. **Check the speed.** Run `node tools/bench.mjs`. `'PreToolUse git'` must stay
   within 7. Write the number in the PR.

## Task 2: an unreadable `.forgotten` hides the handoff's turns

Files: `src/handoff-log.mjs` and `test/handoff-log.test.mjs`.

1. **Write the failing test.** Make a store whose `journal/.forgotten` exists
   but can't be read, then run a Stop.
   - On Linux and macOS, use `chmod 000`.
   - On Windows, make `.forgotten` a directory, which gives EISDIR. Use the
     same trick for both if it works on all three systems.
   - The forgotten exchange must not appear in `handoff.md`. Today it does.
2. **Fix `:847`.** On a read error other than ENOENT, put none of this turn's
   exchanges into the handoff. Use the same rule as `:1183`, and refer to it in
   a one-line comment.

## Task 3: an unreadable `.off-periods`

Files: `src/store.mjs` and `test/journal.test.mjs` (or `test/handoff-log.test.mjs`).

1. **Write the test first.** Make `.off-periods` unreadable (a directory, as in
   task 2), then run a Stop on a turn asked during a period.
2. **If the Stop writes nothing to the journal or the handoff and records the
   failure:** the test passes on master. Keep it as a regression test, add a
   one-line comment in `wasOff` ("a read error throws: the Stop records it and
   writes nothing"), and change no other code.
3. **If anything is written:** the test fails. Then `wasOff` catches errors
   other than ENOENT and returns `() => true`.

## Task 6: doctor uses the store's stale-lock rule
