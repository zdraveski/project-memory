Before you install

Three things you probably already have.

1

Claude Code

With its built-in memory on. It's on unless you turned it off.

To check, type /memory
2

Node.js 20 or newer

A free program. It's what runs project-memory.

From nodejs.org (LTS)
3

Git

A free program that keeps the history of your notes. Without it, everything works except bringing back old versions.

From git-scm.com

Not sure? Ask Claude: Do I have Node.js 20 or newer, and Git?
