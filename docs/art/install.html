Install

Install it in four steps.

1

Add it to Claude Code

/plugin marketplace add zdraveski/project-memory
2

Install it

In the menu, choose to install it for you (user scope).
/plugin install project-memory@project-memory
3

Restart Claude Code

Close Claude Code and open it again.
4

Check that it works

Every line should start with ok.
/project-memory:memory doctorok
